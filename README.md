# Codebase-Explainer
Explains your Codebase in plain English
Requires Chrome or Edge (WebGPU not supported in Firefox/Safari yet)
First load takes time depending on model size and the user's connection
Quality is noticeably below Claude/GPT — fine for explaining simple-to-medium code, struggles with complex architecture
Needs a reasonably modern GPU (2019+ integrated graphics usually works for the 1B model)
